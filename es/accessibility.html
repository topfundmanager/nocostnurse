Declaración de accesibilidad

Estamos comprometidos a garantizar que nuestro sitio web y nuestros servicios sean accesibles para todos.

Nuestro Compromiso

No Cost Nurse se compromete a garantizar la accesibilidad digital para las personas con discapacidad. Estamos mejorando continuamente la experiencia del usuario para todos y aplicando las medidas pertinentes. estándares de accesibilidad para garantizar que brindamos igualdad de acceso a todos los usuarios.

Estado de conformidad

Nos esforzamos por cumplir con las Pautas de accesibilidad al contenido web (WCAG) 2.1, Nivel AA. Estos Las pautas explican cómo hacer que el contenido web sea más accesible para personas con discapacidades y más. fácil de usar para todos.

Funciones de accesibilidad

Este sitio web incorpora las siguientes características de accesibilidad:

Navegación y estructura

  • Saltar enlaces: Los enlaces para omitir navegación permiten a los usuarios evitar el contenido repetitivo y ir directamente al contenido principal.
  • HTML semántico: La jerarquía de encabezados y los elementos semánticos adecuados ayudan Las tecnologías entienden la estructura de la página.
  • Pan rallado: Las rutas de navegación claras ayudan a los usuarios a comprender su ubicación dentro el sitio.
  • Navegación consistente: Los menús de navegación aparecen en la misma ubicación en todos los página.

Diseño Visual

  • Contraste de color: Los colores del texto y del fondo cumplen con los requisitos de contraste de WCAG AA.
  • Texto redimensionable: El tamaño del texto se puede cambiar hasta un 200% sin pérdida de contenido o funcionalidad.
  • Indicadores de enfoque: Los estados de enfoque visibles ayudan a los usuarios del teclado a navegar por el sitio.
  • Diseño Responsivo: El sitio se adapta a diferentes tamaños y orientaciones de pantalla.

Imágenes y medios

  • Texto alternativo: Todas las imágenes informativas incluyen texto alternativo descriptivo.
  • Imágenes decorativas: Las imágenes que son puramente decorativas están debidamente marcadas para ser ignoradas por las tecnologías de asistencia.

Formularios y elementos interactivos

  • Etiquetas: Todos los campos del formulario tienen etiquetas asociadas.
  • Mensajes de error: Los errores de validación de formularios se identifican y describen claramente.
  • Accesibilidad del teclado: Todos los elementos interactivos son accesibles mediante el teclado.
  • Atributos de ARIA: Las etiquetas y roles ARIA apropiados mejoran la tecnología de asistencia apoyo.

Compatibilidad con tecnología de asistencia

Nuestro sitio web está diseñado para ser compatible con:

  • Lectores de pantalla (JAWS, NVDA, VoiceOver, TalkBack)
  • Software de ampliación de pantalla
  • software de reconocimiento de voz
  • Navegación solo con teclado

Compatibilidad del navegador

Este sitio web está optimizado para los siguientes navegadores:

  • Google Chrome (dos últimas versiones)
  • Mozilla Firefox (dos últimas versiones)
  • Apple Safari (dos últimas versiones)
  • Microsoft Edge (dos últimas versiones)

Limitaciones conocidas

Somos conscientes de las siguientes limitaciones y estamos trabajando activamente para abordarlas:

  • Es posible que algunos documentos PDF antiguos no sean totalmente accesibles. Estamos trabajando para corregir estos archivos.
  • Es posible que el contenido de terceros (como mapas o vídeos integrados) no cumpla con todos los estándares de accesibilidad.

Acceso alternativo

Si tiene dificultades para acceder a algún contenido o funcionalidad de nuestro sitio web, comuníquese con nosotros. nosotros se comprometen a proporcionar información en formatos alternativos cuando se solicite, incluyendo:

  • Documentos en letra grande
  • Descripciones de audio
  • Asistencia telefónica
  • Soporte en persona

Accesibilidad en Nuestros Servicios

Más allá de nuestro sitio web, No Cost Nurse está comprometido con la accesibilidad en todos los aspectos de nuestra operaciones:

  • Nuestro personal está capacitado para brindar adaptaciones a personas con discapacidades.
  • Brindamos servicios en el domicilio del paciente, eliminando barreras de transporte.
  • Los materiales escritos se pueden proporcionar en formatos accesibles.
  • Se encuentran disponibles adaptaciones de comunicación (como intérpretes) previa solicitud.

Mejora continua

Estamos comprometidos a mejorar continuamente la accesibilidad. Nuestros esfuerzos incluyen:

  • Auditorías periódicas de accesibilidad de nuestro sitio web.
  • Capacitación del personal sobre mejores prácticas de accesibilidad.
  • Incorporar los comentarios de los usuarios en las mejoras.
  • Mantenerse al día con las normas y directrices de accesibilidad
